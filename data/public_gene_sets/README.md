# Public Gene-Set Libraries

These versioned GMT files support local and reproducible enrichment analyses.

| File | Source | Analysis role |
|---|---|---|
| `ChEA_2022.gmt` | ChEA 2022 | TF-target enrichment |
| `TRRUST_Transcription_Factors_2019.gmt` | TRRUST 2019 | Curated TF-target enrichment |
| `GO_Biological_Process_2023.gmt` | Gene Ontology Biological Process 2023 | Functional annotation |
| `WikiPathways_2024_Mouse.gmt` | WikiPathways 2024 Mouse | Mouse pathway annotation |

The libraries were retrieved through the Enrichr gene-set library
interface on 2026-09-24 and retained locally to support reproducible
offline execution.

TF-target-set membership indicates a database-supported association.
It does not establish direct binding, regulator activity, directionality,
or causal regulation in the current experiment.
